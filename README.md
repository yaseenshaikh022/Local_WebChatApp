# Local_WebChatApp

A responsive, browser-based web chat interface starter project built with plain HTML, CSS, and JavaScript.

## Features

- Responsive chat layout for desktop and mobile
- Send messages with Enter (Shift+Enter inserts a new line)
- Starter prompts and local demo replies
- Chat history saved in the current browser using localStorage
- User messages rendered as text rather than interpreted as HTML
- No build tools or package installation required

## Important limitations

This is a **front-end demo**, not a production or multi-user messaging service.

- Messages are stored only in the current browser profile.
- Other users and devices cannot see your messages.
- Demo replies are not generated by an AI model.
- There is no server, account system, authentication, encryption, or real-time delivery yet.
- The public GitHub repository contains source code, not your browser's local chat history.

## Run locally

Open `index.html` in a modern browser, or run this command in the project directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
